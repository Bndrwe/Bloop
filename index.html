How it works

Bloop keeps one eye open.

  1. 1Press Start. A Pomodoro session, or let it watch without one.
  2. 2It sees what's in front. The app and the site, every 2 seconds.
  3. 3It nudges when you drift. A worried face first, then a reminder.

01 Live focus score

a score that notices.

Every day starts at 100. The score drops while you drift and climbs back when you return. Bloop judges what's actually on screen: a lecture on YouTube counts as study, gameplay doesn't.

02 Deadlines and plan

what's due, and a plan for it.

Log in to Brightspace, or paste your calendar link, to see what's due next. Then Bloop builds a week of study blocks around it with the AI you already use.

03 Reminders when you drift

a gentle psst when you wander.

  1. right awayOpen a distracting site and Bloop looks worried and says something kind.
  2. 1 minA speech bubble and a macOS or Windows notification.
  3. every 2 minAnother reminder at 3, 5, 7 minutes, until you're back.
  4. back on trackBloop cheers, and the cycle starts over.

Install help

opening Bloop the first time

Bloop isn't code-signed yet, so your computer asks you to confirm once. After that it opens normally, and updates keep your settings and history.

On a Mac

  1. Open the .dmg and drag Bloop into Applications.
  2. Right-click Bloop → Open → Open.
  3. If macOS says the app "is damaged", run xattr -cr /Applications/Bloop.app in Terminal and open it again.
  4. Allow Screen Recording and Automation when asked, then click Relaunch Bloop. Bloop lives in the menu bar.

On Windows

  1. Run Bloop-Setup-1.0.0-win-x64.exe.
  2. If SmartScreen says "Windows protected your PC", click More info → Run anyway.
  3. Bloop shows up in the Start menu and in the tray by the clock (maybe under the ^).

On Linux

  1. Run chmod +x Bloop-*.AppImage, then open it. On Ubuntu 24.04+, add --no-sandbox if it closes straight away.
  2. Or install the .deb: sudo apt install ./bloop_1.0.0_amd64.deb
  3. Focus tracking needs x11-utils and an X11 session.

FAQ

questions, answered

Is Bloop really free?

Yes. Bloop is free and open source. Download it from the GitHub releases page, or build it yourself from the code.

What does it look at?

It checks which app is in front every 2 seconds and, in a browser, which site. On macOS it reads the tab URL; on Windows it works out the site from the window title. Everything is judged on your computer and never leaves it.

Do I need AI?

No. The focus score, reminders and Brightspace deadlines all work without it. AI turns on the weekly study plan, chat and smarter judging of pages like YouTube. Pick a cloud AI you already use (Claude, Codex, Gemini or an API key) or Ollama on your own computer in Settings → AI.

How can it tell a lecture from gameplay?

Some sites could be study or not. Bloop judges those by what's on the page: its own rules first, then the AI you set up. With no AI, an unclear page counts as distracting.

Does it work without starting a session?

Yes. With Watch without a session (on by default), Bloop reacts to distractions anyway and shows a live score. That time is never saved as a session or counted in your stats.

Can I hide the pet?

Press Ctrl+Shift+B (⌘⇧B on a Mac) anywhere. Bloop keeps tracking while hidden and pops up for a few seconds when it nudges you. The same shortcut brings it back.

Can I chat with Bloop?

Yes, as a small extra. A chat window for study questions, saved on your computer, opens from the panel, the study plan or the tray. It uses the AI you set up.

Why does my computer warn me when I install it?

The apps aren't code-signed yet. See install help for the one-time steps.
